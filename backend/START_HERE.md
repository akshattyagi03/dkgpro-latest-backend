## 🎯 Payment Flow

```
User visits /payment
    ↓
Server renders EJS page
    ↓
User enters amount & address
    ↓
User clicks "Pay Now"
    ↓
Frontend creates order
    ↓
Razorpay checkout opens
    ↓
User completes payment
    ↓
Frontend verifies payment
    ↓
Order confirmed
    ↓
Cart cleared
    ↓
Success page
```
